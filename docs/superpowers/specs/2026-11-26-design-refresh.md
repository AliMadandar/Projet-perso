# Rivqo design refresh

The user requested a first design pass directly in the project, to review visually and iterate. Improve the public homepage and existing workspace, including mobile, without changing financial calculations or access rules.

Direction: warm off-white, dark forest/teal accents, locally bundled Inter, restrained borders, generous spacing, readable forms and clear primary actions. Use existing French copy and routes. Present Nilo as assistance with user review; do not imply Gemini is always configured. Keep light/dark themes, reduced-motion support, keyboard focus, Persian RTL, and printable documents.

Approach: update existing HTML/CSS and presentation strings in the dependency-free app. A framework rewrite adds unnecessary scope; a separate mockup would not deliver the requested project changes. These are implementation choices made for this first pass, not separately approved design preferences.

Landing: benefit-led headline, illustrative quote, three-step journey, Nilo explanation, mobile use, real demo CTA. No invented testimonials or commercial claims.
Workspace: clear dashboard heading, restrained summary cards, Nilo shortcut, consistent navigation, forms, editor and login. Mobile: readable cards, generous tap targets and existing bottom navigation.
